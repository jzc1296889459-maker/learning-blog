## 为什么从网站开始

我计划通过一系列学习项目了解 AI 和 Agent。项目 0 不是 AI 项目，而是先搭建一个网站，用它记录后面的学习过程。

开始时，我几乎没有编程和工程经验。因此，这个网站本身也是学习的一部分。

## 到目前为止完成的事情

- 安装并使用 Bun 运行项目
- 了解 Astro 项目的基本目录结构
- 修改网站名称、作者、简介和 GitHub 链接
- 建立中文优先的双语结构
- 简化首页、About、Blog 和 Notes 页面
- 删除原作者的文章、图片和不需要的功能
- 关闭评论、统计和数据库相关功能
- 检查字体、图标和第三方资源的许可证
- 使用 Git 记录并推送每个阶段的修改

## 我目前学到的东西

### 配置和内容不同

网站配置决定标题、语言和菜单等整体行为；Markdown 和 MDX 文件则保存具体文章。

### 检查比猜测更可靠

遇到错误时，错误信息、文件搜索和 Git diff 通常可以帮助确定问题发生在哪里。

### 小步修改更容易排错

每完成一组相关修改，就进行检查和提交。这样出现问题时，更容易知道是哪次修改造成的。
